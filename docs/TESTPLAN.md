# Student account application test plan

This plan describes the behavior implemented by the current COBOL application
in [`src/cobol/`](../src/cobol/). It covers both the menu flow and the account
balance operations. The initial balance is `1000.00`; run cases that depend on
this starting balance in a fresh application process unless their steps say
otherwise.

Some cases document behavior the code does not define, such as invalid numeric
input, negative amounts, and balance overflow. These are characterization tests
for the COBOL implementation and decisions for business stakeholders, not
assumptions about the desired Node.js behavior. Record actual observed output
and agree the expected behavior before implementing those cases in Node.js.
